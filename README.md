# UFC Fight Center

Современный mobile-first дашборд (`max-width: 480px`) для мониторинга ростера бойцов UFC, просмотра грядущих турниров и ведения персонального списка «Любимых бойцов» с отслеживанием их статистики.

## Возможности

### Главная страница (`/`)

- Интерактивный список ТОП-бойцов (ростер).
- Фильтрация по **весовым дивизионам** (Heavyweight, Lightweight, Welterweight и т.д.) и поиск по фамилии — состояние завязано строго на **URL Search Params** (фильтр можно шарить ссылкой).
- Анонс ближайшего номерного турнира (например, UFC 334 / 335) с таймером обратного отсчёта.

### Страница бойца (`/fighter/$fighterId`)

- Профиль бойца: аватар, рекорд (W-L-D), страна, статус (Чемпион / Топ-контендер).
- Радарная диаграмма или блоки характеристик (Striking, Grappling, Тейкдауны).
- Кнопка «Добавить в свой Кэмп» (Watchlist).

### Глобальное состояние

- **My Camp** — список избранных бойцов, за которыми пользователь следит особенно пристально. Сохраняется в `LocalStorage`.

## Структура проекта

Проект организован по принципам **Feature-Based Design** (фиче-ориентированная архитектура): код группируется не по техническому типу (все компоненты в одной папке, все хуки в другой), а вокруг бизнес-фич. Вся логика конкретной фичи — компоненты, хуки, сторы, запросы — живёт рядом в собственной папке `features/`. Это упрощает навигацию по коду, изолирует фичи друг от друга и позволяет легко добавлять или удалять функциональность, не затрагивая соседний код.

```
src/
├── api/          # Запросы к серверу/мокам (fighterApi.ts)
├── components/   # Переиспользуемые UI-примитивы (Button, Badge, Skeleton)
├── data/         # Моковые данные (fighters.mock.ts)
├── features/     # Бизнес-фичи со своими компонентами и хуками
│   ├── roster/   # Всё для ростера (FighterCard.tsx, DivisionSection.tsx)
│   └── camp/     # Всё для «Моего Кэмпа» (store, кнопки добавления)
├── routes/       # Только страницы-роуты (связывают фичи и URL)
├── types/        # Глобальные TS-интерфейсы (fighter.ts)
└── utils/        # Чистые хелперы (cn.ts)
```

Кратко по слоям:

- **`features/`** — сердце архитектуры: каждая фича (ростер, «Мой Кэмп») самодостаточна и содержит всё, что ей нужно.
- **`routes/`** — тонкий слой: страницы только собирают фичи вместе и связывают их с URL.
- **`components/`, `utils/`** — общий переиспользуемый код без привязки к конкретной фиче.
- **`api/`, `data/`, `types/`** — инфраструктурный слой: доступ к данным, моки и глобальные типы.

> `src/routeTree.gen.ts` генерируется плагином `@tanstack/router-plugin` — не редактируйте его вручную.
